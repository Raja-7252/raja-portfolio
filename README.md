## About the site

A warm, modern, human-centered portfolio built with plain HTML, CSS, and JavaScript — no frameworks, no build step, fast on any hosting.

- **index.html** — Home: hero, about, skills, impact dashboard, experience, case study previews, contact
- **case-studies.html** — Three detailed case studies with measurable outcomes
- **css/style.css** — Design system (ivory / forest green / terracotta / charcoal palette)
- **js/main.js** — Scroll animations, mobile menu, active-nav highlighting
- **js/charts.js** — Live charts (Chart.js via CDN): bar, doughnut, and line
- **assets/** — Healthcare hero image + downloadable resume (`resume.pdf`)

## How to update

- **Resume:** replace `assets/resume.pdf` with your latest version (keep the filename).
- **Content:** edit `index.html` / `case-studies.html` directly — plain HTML, easy to find sections by heading.
- **Charts:** edit values in `js/charts.js`.

To publish changes: `git add -A && git commit -m "update" && git push` — GitHub Pages updates automatically.
